# Design reference

`home-prototype-2026-11-01.html` is the home page design the founder approved on 2026-11-01 (docs/DECISIONS.md):
the magazine-type layout with the 9:16 hero reel, staggered case spreads, the short-form row, the Why list and the
red closing page, with all of its motion. It is a standalone prototype, not part of the build. Its media paths
(`../assets/...`) point at the design workspace and do not resolve here; the matching site files live under
`public/portfolio/` and `public/shorts/`.
