# 排版细节待办（2026-10-31 视觉检查）

2026-10-31 用 5 个 AI 检查员逐页看了公开版网站在电脑（1440）、平板（768）、手机（390）上的截图，一共提出 93 条意见。下面是去重、去掉已修好和文案类之后剩下的排版问题，按文件分成 4 组（分组时尽量不让两组改同一段 CSS）。创始人决定暂不继续，留到以后做。

- 修改原则：保持现有设计语言（固定浅色主题、Newsreader 标题字体、色块、留白、案例图片 object-fit: contain），只做最小改动，不改英文文案；对比度按 WCAG AA 计算（正文 4.5:1，大字 3:1）。
- 每组改完建议用 Playwright 在 390 / 768 / 1440 三个宽度截前后对比图，并跑 `npm test`、`npm run test:internal`、`npm run lint`。
